# SQL Introduction

This project covers the basics of SQL: databases, tables, DDL, DML, and simple queries in MySQL.

## Learning Objectives
- What's a database and a relational database
- What SQL stands for and what MySQL is
- How to create a database and tables
- What DDL and DML stand for
- How to SELECT, INSERT, UPDATE, and DELETE data
- What are subqueries
- How to use MySQL functions
