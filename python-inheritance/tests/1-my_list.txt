The ``1-my_list`` module
==========================

Using ``MyList``
------------------

First import the class:

    >>> MyList = __import__('1-my_list').MyList

Check instantiation:

    >>> my_list = MyList()
    >>> print(my_list)
    []

Append some integers:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Print sorted, and confirm the original list is unchanged:

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Test with an empty list:

    >>> empty_list = MyList()
    >>> empty_list.print_sorted()
    []

Test with a list already sorted:

    >>> sorted_list = MyList()
    >>> sorted_list.append(1)
    >>> sorted_list.append(2)
    >>> sorted_list.append(3)
    >>> sorted_list.print_sorted()
    [1, 2, 3]

Test with a single element:

    >>> one_elem = MyList()
    >>> one_elem.append(42)
    >>> one_elem.print_sorted()
    [42]

Check that MyList is still a list:

    >>> isinstance(my_list, list)
    True
