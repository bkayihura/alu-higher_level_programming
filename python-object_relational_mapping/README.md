# Python - Object Relational Mapping

## Description
This project covers connecting Python to a MySQL database, first using
raw SQL via `MySQLdb`, then using the SQLAlchemy ORM to map Python
classes to database tables.

## Files
- `0-select_states.py` to `5-filter_cities. MySQLdb scriptspy` 
- `model_state.py`, `model_city. SQLAlchemy model definitionspy` 
- `6-model_state.py` to `14-model_city_fetch_by_state. SQLAlchemy scriptspy`
